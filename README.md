# Line Following Robot

An autonomous robot that follows a black line track in a real time.
## Components Used
- Arduino Uno
- IR Sensors (x2)
- L298N Motor Driver
- DC Motors (x2)
- 9V Battery

## How It Works
- IR sensors detect the black line on the surface
- Robot follows the line automatically

## Skills Used
- C++ / Arduino Programming
- Embedded Systems
- PWM Motor Control
